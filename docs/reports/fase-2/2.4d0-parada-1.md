## 1. A regra

`Classe.m(..)`, com `Classe` uma classe do projeto, resolve pela cadeia da própria classe, para cima (C3, DEC-43). Para na primeira que declara `m` e nunca desce para subclasses. O link sai `type`, com `basis: type`. Um `unique` confirmado continua `unique`.

**Quando vale.** O receptor é um nome, ou nomes com pontos, e não tem tipo escrito. Um nome com tipo escrito é uma variável, e valem as regras de antes. O nome é lido pela DEC-42, no lugar da chamada.

| Como o nome chega | Como é lido | No Healthchecks (medido) |
|---|---|---|
| `from p import C` (no módulo ou dentro da função) | O import, com reexportação de até três passos | 2 das 18; 24 das 27 `unique` |
| Classe do mesmo módulo | A `class` do módulo | 16 das 18; 2 das 27; as 26 sem candidato |
| Alias: `import C as D`, `D = C`, `k = C` na função | O alias (N8) | 0 |
| `modulo.C.m(..)`, `a.b.C.m(..)` | O módulo do projeto e a classe dele | 0 |
| Aninhada: `C.Dentro.m(..)`, `modulo.C.Dentro.m(..)` | A classe e, dentro dela, a classe daquele nome declarada no próprio corpo | 8, todas `X.ErrorModel` ou `Signal.Reply`, do pydantic |

A 27ª `unique` é `Ping.GetBodyError()`: o receptor é `Ping`, e o nome chamado é uma classe aninhada, construída e não chamada.

**O que sai em cada resultado da busca:**
- **Achado** antes de qualquer base de fora: o método.
- **Base de fora antes, ou ninguém declara:** não há link pela classe. Saem os candidatos que não estão na cadeia de `C` (DEC-43, "fora da cadeia"), só para cima. Sem nenhum, fica sem candidato.
- **A classe não pode ser lida, ou o nome não é método:** vale o que valia.

## 7. Riscos e limites

- Uma base de fora que delega, ou um método posto de fora (`C.m = outro`), perde o candidato: o mesmo risco da DEC-43, aqui estendido à chamada pelo nome da classe. 0 casos.
- Um decorador de classe que troca a classe não é visto quando a própria classe declara `m`, como no 2.4b.
- `Protocol`, metaclasse e classe aninhada herdada não decidem.
- Uma classe dentro de uma função ou de um `if` não tem as bases lidas (DEC-43): só vale o método dela mesma.
- O receptor de fora acima do teto (HC-169) continua como no 2.2.
