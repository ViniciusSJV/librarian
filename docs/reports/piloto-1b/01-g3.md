## Limitações e observações

- **O `node_limit` não foi visto em dados reais.** Está provado pelo teste unitário e pelo HTTP com o projeto sintético.
- **Quais links sobram no teto segue a ordem dos ids das arestas, não a ordem das linhas.** No sintético, por exemplo, `f5` (linha 7) ficou de fora junto com `f56`–`f65`. Isso já acontecia antes do G3; o que muda é que agora fica visível.
- **`no_candidate_in_project` reúne chamadas com nome** (`missing_helper`) **e sem nome** (`handlers[0]`), como decidido. Só o texto distingue as duas.
- **No Healthchecks, a lista sem candidato é longa**: chamadas a ORM, `statsd`, builtins. Por isso a seção fica recolhida.
